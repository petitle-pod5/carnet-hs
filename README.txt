CARNET HS V3.3 — SAUVEGARDE

Nouveautés :
- sauvegarde automatique locale à chaque enregistrement ;
- conservation des 10 dernières versions de sauvegarde dans le navigateur/téléphone ;
- restauration de la dernière sauvegarde automatique ;
- import d'un fichier JSON de sauvegarde ;
- export JSON manuel ;
- export CSV ;
- les fonctions V3.2 restent présentes : historique jour/semaine/mois/tout, semaine ISO, totaux, profil mémorisé, validation salarié et chef.

Important : cette version sécurise les données sur l'appareil. Elle ne fait pas encore de synchronisation cloud entre téléphone et PC. Cette étape viendra après validation de la sauvegarde.
