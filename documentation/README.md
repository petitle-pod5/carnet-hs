# Documentation Carnet HS

Ce dossier centralise les documents **destinés à être publiés** avec le projet Carnet HS.

## Règle de sécurité

Le dépôt `petitle-pod5/carnet-hs` est public. N'y déposer aucun document interne ou confidentiel : suivi détaillé du développement, notes de travail, données personnelles, éléments commerciaux non publiés, identifiants, exports réels ou fichiers contenant des informations de salariés.

Les documents internes (Word et Excel de travail) doivent être conservés dans un dépôt GitHub **privé** distinct. Le dépôt privé dédié reste à créer ; aucun document interne n'est publié ici.

## Règles de versionnement

- Conserver les fichiers sources Word et Excel dans le dépôt privé.
- Utiliser des noms explicites avec date ou version, par exemple `Historique_developpement_Carnet_HS_2026-11-07.docx`.
- À chaque séance de travail, consigner la date, les changements, les tests, les décisions et les points ouverts dans l'historique.
- Ne jamais modifier la production V3.4.1 sans accord explicite.
- Ne publier un document dans le dépôt public qu'après contrôle de son contenu et validation de sa destination.
